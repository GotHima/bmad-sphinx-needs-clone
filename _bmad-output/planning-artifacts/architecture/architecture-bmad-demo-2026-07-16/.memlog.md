- (decision) AD-1: All DB access server-side only — lib/db.ts carries import 'server-only'; Client Components never import db/queries/actions directly
- (decision) AD-2: Server Actions own mutations; RSC pages own reads; single Route Handler exception for link autocomplete (GET streaming pattern)
- (decision) AD-3: Backlinks computed at read time via JOIN on need_link — no denormalized backlinks column, prevents stale state
- (decision) AD-4: ID generation server-side in Server Action — PREFIX_padded(MAX(seq)+1); UNIQUE constraint on need.id; violation returned as structured field error
- (decision) AD-5: Filter/sort state in URL search params — URL is single source of truth; filters bookmarkable; no parallel React state
- (decision) AD-6: need_link has only from_id + to_id columns — no link_type in MVP; v2 adds nullable column via ALTER TABLE, no backfill
- (decision) AD-7: Need-type color from DB prop at render time — inline style/CSS custom property, never a static color map or Tailwind class
- (decision) AD-8: Schema init via CREATE TABLE IF NOT EXISTS at module load in lib/db.ts — no migration framework for single-user local SQLite
- (decision) AD-9: 'open' status seeded via INSERT OR IGNORE at DB init; undeletable enforced in Server Action
